Política de privacidad de CardioScan

Última actualización: 7 de octubre de 2026.

Resumen: CardioScan procesa fotografías de electrocardiogramas y resultados de análisis, que pueden contener información de salud. Estos datos se almacenan para permitir el funcionamiento del historial del usuario. El uso de datos para mejorar los modelos o sistemas de análisis debe contar con una autorización específica del usuario, separada del uso necesario para generar el resultado solicitado.

1. Responsable y alcance

Esta Política de privacidad explica cómo CardioScan recopila, utiliza, almacena y elimina información cuando una persona utiliza la aplicación móvil CardioScan. Para consultas relacionadas con privacidad, puede escribir a jesus.viveros00@usc.edu.co.

2. Datos que procesa CardioScan

CardioScan puede procesar: (a) fotografías o imágenes de electrocardiogramas aportadas por el usuario; (b) el resultado o interpretación automatizada generada a partir del ECG; (c) datos técnicos estrictamente necesarios para transmitir la solicitud, mantener la seguridad del servicio y solucionar errores; y (d) información derivada de los análisis que, cuando el usuario lo autorice expresamente, puede utilizarse para evaluar y mejorar el rendimiento del sistema.

3. Cámara y fotografías

El permiso de cámara se solicita para permitir que el usuario capture un electrocardiograma. El usuario debe procurar que la fotografía no incluya nombres, documentos de identidad, números de historia clínica u otros identificadores personales que no sean necesarios para el análisis.

4. Envío y procesamiento

CardioScan requiere conexión a internet. La imagen del ECG es transmitida a servidores propios de CardioScan para procesar la solicitud y generar la interpretación automatizada. La transmisión debe realizarse mediante mecanismos de seguridad apropiados, incluido cifrado en tránsito.

5. Almacenamiento e historial

Las imágenes de ECG y sus resultados pueden conservarse para que el usuario pueda acceder posteriormente a su historial dentro de la aplicación. Estos datos permanecen almacenados hasta que el usuario los elimine mediante las funciones disponibles en la aplicación o solicite su eliminación a través del correo de contacto indicado en esta política.

6. Uso de datos para mejorar CardioScan

Además del procesamiento necesario para responder a la solicitud del usuario, CardioScan puede utilizar datos derivados de electrocardiogramas para evaluar y mejorar la precisión, cobertura diagnóstica y desempeño del sistema. Debido a que se trata de información médica sensible, este uso adicional debe realizarse únicamente cuando el usuario haya otorgado una autorización expresa y específica para esa finalidad.

Cuando sea técnicamente posible, CardioScan debe eliminar o reducir identificadores innecesarios antes de utilizar información con fines de mejora. La negativa a autorizar este uso adicional no debe impedir el uso básico de la función de análisis del ECG.

7. No utilización con fines publicitarios

CardioScan no utiliza fotografías de ECG, resultados médicos ni información derivada de ellos para publicidad dirigida, marketing basado en perfiles de salud ni venta de datos a anunciantes.

8. Conservación y eliminación

Las imágenes y resultados se conservan mientras el usuario decida mantenerlos en su historial. El usuario puede eliminarlos cuando lo desee mediante las opciones de eliminación disponibles en CardioScan. También puede solicitar la eliminación de sus datos escribiendo a jesus.viveros00@usc.edu.co. Tras una solicitud válida, los datos deben eliminarse de los sistemas activos dentro de un plazo razonable, salvo que exista una obligación legal que exija conservarlos.

9. Consentimiento y retiro de autorización

Antes de utilizar datos médicos para una finalidad adicional a la generación y conservación del análisis solicitado —incluido el mejoramiento del sistema— CardioScan debe presentar al usuario información clara y solicitar su consentimiento. El usuario puede retirar posteriormente esa autorización. El retiro no afecta el tratamiento realizado legítimamente antes de la revocación.

10. Seguridad

CardioScan busca aplicar medidas técnicas y organizativas razonables para proteger la información médica, incluyendo protección de las comunicaciones, controles de acceso y medidas destinadas a impedir el acceso no autorizado. Ningún sistema conectado a internet puede garantizar una seguridad absoluta.

11. Información médica y limitaciones

CardioScan utiliza inteligencia artificial para ofrecer una interpretación automatizada de apoyo. El resultado no sustituye una valoración médica profesional, no constituye por sí solo un diagnóstico definitivo y no debe utilizarse como única base para iniciar, modificar o suspender un tratamiento ni para decidir que no es necesario consultar a un profesional sanitario.

12. Menores de edad

CardioScan no está diseñada específicamente para recopilar directamente información de salud de menores sin la participación y autorización que resulte legalmente necesaria. Si el servicio se utiliza con información perteneciente a un menor, el usuario responsable debe asegurarse de contar con las autorizaciones aplicables.

13. Cambios a esta política

Esta política puede actualizarse para reflejar cambios en CardioScan, en sus sistemas o en las obligaciones legales aplicables. La fecha de la versión vigente se mostrará al inicio de esta página.

14. Contacto y derechos del usuario

Para solicitar información, corrección, retiro de autorización o eliminación de datos, puede escribir a jesus.viveros00@usc.edu.co. CardioScan responderá de acuerdo con las obligaciones legales aplicables.
